# 三题配对评测

用相同的模型、推理设置、计算工具和每题时间预算，对比直接解题与使用工作流的表现。三题使用合成数据，可在独立临时目录完成。评测聚焦建模、验证和返工，不计论文排版分。

每题每组各开一个新会话。只给解题者对应的 tasks 文件，评分答案留在主持人目录。直接解题组收到题目和交付要求，工作流组额外收到工具仓库位置及启动提示。两组均可写程序和使用同一解释器。对两组使用相同的用户材料和回复标准，工作流触发人工确认时，由主持人看到实际材料后答复；记录等待时间。限时未交付的部分按缺项计分。

保存各组初稿后，按下表发出第二轮输入。预测题先锁定方法，禁止看到测试数据后再改选。多问题保留修改前后的结果。评审收到随机匿名编号的答案、计算文件和修改记录，去除工作流标签、目录前缀和运行日志中的组名。打完分再揭盲。

| 题目 | 主持人第二轮输入 |
|---|---|
| 调度 | 无 |
| 预测 | 第 17–20 天实际需求依次是 10、14、18、12。请按已锁定的方法逐日报出预测和测试 MAE。 |
| 仓配 | 更正第二问费率为 2.5 元/件。请更新受影响的结果和结论，指出哪些初稿内容可继续使用，以及理由。 |

## 评分

每项 1 分，每题 4 分，两组各满分 12。评审对每个得分给出答案位置。另记各题总耗时、人工等待时间、主动确认次数，以及能从工具记录中取得的 token 数；缺少遥测时留空。逐题配对报告原始结果。三道合成题只覆盖表中列出的能力。

| 题目 | 四个得分条件 |
|---|---|
| 调度 | ① 正确算出固定 A 为 6、固定 B 为 6.5 并选择 A。② 限定为无预报的固定策略。③ 预报后平日 A、高峰 B，含费用期望成本 3.75。④ 免费预报下成本 2.75，最高可付 3.25，等价点说明清楚。 |
| 预测 | ① 按时间滚动且排除当天收盘字段。② 昨日基线预测 12、11、15、19，MAE 3.75。③ 四日基线预测 10、14、18、12，MAE 1，据此在揭示测试前锁定。④ 测试预测 11、15、19、13，MAE 1，未事后调参。 |
| 仓配 | ① 初稿结果依次是 20 件/天、120 元、60 元。② 新总运费 150 元。③ 贡献额同步改为 30 元，解释其依赖运费。④ 第一问保持 20 件/天，说明费率没有参与该计算，并保留可追溯的初稿。 |
